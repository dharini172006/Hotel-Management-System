# Hotel Management CRUD
A ful-stack Hotel Management System with React, Node.js, Express and PostgreSQL.
## features


-Add Hotel
-Edit Hotel
-Delete Hotel
-View Hotel Details
-Image Upload
-Search Hotel
-Price Fiter
-Sort Price
-Pagination
-Map View
-PostgreSQL


## Tech Stack
-React(Vite)
-Node.js
-Express.js
-PostgreSQL
-Multer
-Axios
-React Router
-Leaflet
